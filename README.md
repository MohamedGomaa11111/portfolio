## 🚀 How to Run Locally

### Option 1: Direct Double Click
Simply double-click `index.html` to open the portfolio in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
Open PowerShell or Terminal in this folder and run:

```bash
python -m http.server 3000
```

Then visit: [http://localhost:3000](http://localhost:3000)

## ☁️ How to Deploy on GitHub Pages (Free Hosting)

To make your portfolio accessible worldwide under your own personal link (`https://MohamedGomaa11111.github.io`):

1. **Create a new repository on GitHub** named:
   ```
   MohamedGomaa11111.github.io
   ```
   *(Must match your exact GitHub username)*

2. **Upload the contents of the `portfolio` folder** to the root of this new repository:
   - `index.html` must be in the root directory.
   - `assets/` folder must be in the root directory.

3. **Enable GitHub Pages:**
   - Go to your repository **Settings** &rarr; **Pages**.
   - Under **Build and deployment** &rarr; **Branch**, select `main` and `/ (root)`.
   - Click **Save**.

4. Your portfolio will be live at:
   **`https://mohamedgomaa11111.github.io`** 🚀
